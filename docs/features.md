## Tasks and notes

- Add, edit, complete, reopen, delete, filter, and sort tasks.
- Manage [projects](project-renaming.md); HA projects represent lists, including empty lists.
- Edit Markdown notes with live preview, autosave, and conflict choices.
- Change due dates while preserving a datetime's time and offset; see [editing](task-text.md).

## Devices and sync

Work locally without a server, or connect for [reviewed remote updates](live-sync.md). Narrow screens use a single pane, bottom navigation, and swipe switching. Desktop window position, size, maximized state, and native fullscreen are remembered.

Page-zoom gestures are disabled where supported. Scrolling, keyboard input, and OS accessibility magnification remain available.
