# Release v0.15.36

- [Changes](#changes)

## Changes

Align all app-owned modals with Settings styling through one shared surface, typography, field spacing, and action treatment. Add responsive bounds, wrapping action rows, visible keyboard focus, and shared white update footers. Keep wider conflict/update previews and their internal scrolling.

## Compatibility

Dialog content, validation, approval/recovery actions, focus ownership, and dismissal safeguards are unchanged. Remote updates remain title-free. Native system dialogs, server behavior, data formats, dependencies, and signing identity are unchanged.
