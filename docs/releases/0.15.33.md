# Release v0.15.33

- [Changes](#changes)
- [Compatibility](#compatibility)

## Changes

- Update React/DOM, Tauri JavaScript packages, testing-library/types, and the Vite 8, React plugin 6, Vitest 5, jsdom 31, TypeScript 7 toolchain. Refresh npm and compatible native Cargo dependencies while retaining existing audit-fix improvements.
- Make remote-review button accessible names explicit across DOM/toolchain versions and preserve generic fake-reader typing with a spy. Existing behavioral assertions remain intact.
- Keep local/remote task behavior, native window-state patch, and the Android filesystem compatibility pin. No release publication or deployment is implied.

## Compatibility

Tooling requires Node `^22.22.2 || ^24.15.0 || >=26.0.0`; use `npm ci` for the committed graph. Native checks require the platform's Tauri development libraries. Newer Android filesystem/window-state versions are not adopted without their platform/patch validation. See [dependency guidance](../development.md#toolchain-and-dependency-updates).
