## Changes

Return to the originating list picker when canceling local list creation/removal or HA create/delete prompts. Preserve selection and task drafts, restore action focus, and invalidate obsolete picker sessions. Add scroll-surface clearance and local row stacking so blue Add/Rename outlines remain visible. Remove the draft-only sentence and simplify local removal to `Remove <name>`.

## Compatibility

Busy-operation guards, explicit approval/recovery, HA deletion safeguards, wire/storage contracts, dependencies, and signing identity remain unchanged. No server, native system-dialog, publication, or deployment changes are included.
