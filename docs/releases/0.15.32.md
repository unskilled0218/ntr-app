# Release v0.15.32

- [Changes](#changes)

## Changes

- Show server-managed HA lists as projects with friendly names, stable entity IDs, duplicate-name disambiguation, and empty-list visibility. Requires ntr server 0.2.12 or later.
- Route new tasks to the selected/default list without inserting list names into task summaries. Preserve existing literal `+project` text.
- Require confirmation for cross-list moves and expose reconcile/abandon recovery without automatic replay.
- Use server-authorized list creation, display-name renaming, and empty-only deletion rather than rewriting task tokens. Existing local/file project workflows remain unchanged.
- Keep HA credentials server-only, datetime due editing, local fallback, and remote approval. Local validation does not publish packages or images.
