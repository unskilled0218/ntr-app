# Release v0.15.30

- [Changes](#changes)

## Changes

- App publication now prints live stage logs, per-asset upload and verification events, and elapsed-time updates every 15 seconds during dependency installation, tests, and builds.
- Raw tool output stays private to protect signing and API credentials. Failures identify the stage without exposing private details; existing releases still verify read-only.
- Standalone builds announce desktop and Android target starts and completions. Timed-out or interrupted publisher setup/test/build commands stop their process groups without retrying or rolling back remote writes.
