# Release v0.15.28

- [Changes](#changes)

## Changes

- Align app publication with the guarded server release process: configuration, private token files, exact-source annotated tags, artifact manifests, and remote verification.
- Verify completed releases without rebuilding or signing-key access. Refuse partial or conflicting states without automatic deletion or rollback.
- Publish Linux desktop packages and signed universal Android APKs; AAB and Google Play App Signing are not supported by this workflow.
- Keep Android signing files local in gitignored `android-signing/`, preserve existing keys during explicit migration, and check the expected public signing certificate before new Android publication.
